# Veera's Beauty Website

Static marketing website for **Veera's Beauty & Tattoo Studio**.

## Files

- `index.html` - full landing page
- `styles.css` - responsive styling
- `script.js` - services and academy rendering

## Open Locally

You can open `index.html` directly in a browser, or run a simple local server.

Example with Python:

```bash
cd website
python -m http.server 8080
```

Then open:

`http://localhost:8080`

## Deploy

You can deploy this folder easily on:

- Vercel
- Netlify
- GitHub Pages
